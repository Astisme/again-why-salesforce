Why should I use it?

Because Setup navigation is repetitive

Salesforce Setup work often means returning to the same pages across several orgs, copying setup URLs, and remembering which tabs matter for each project.

Again, Why Salesforce keeps those Setup routes close, organized, styled, and portable without sending data elsewhere.

How it works

Get started in 3 steps

1. Install the extension

Use matching browser store link, or latest GitHub release when store install does not apply.

2. Open Salesforce Setup

Go to your Salesforce Setup, where custom tabs should appear.

3. Open the extension popup

Click the extension icon and allow access when your browser asks it, then save your first Setup tab.
